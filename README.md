# pairs-stratification
Pairs Stratification for Scottish bridge clubs, written in Python.

# What does it do?
The program consumes a USEBIO format XML fie containing the results of a bridge tournament and applies "stratification" to the results.

You can choose the ranks at which stratification occurs and choose up to two strata from the overall results. As the ranks are presently hard-coded and the list of ranks is obtained directly from a server for Scottish bridge players, the program is only useful for Scottish bridge clubs. This might change in future.

More detailed information can be found in the Help installed with the program.
