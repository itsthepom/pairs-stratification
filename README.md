# pairs-stratification
Pairs Stratification for Scottish bridge clubs, written in Python.

# What does it do?
The program consumes a USEBIO format XML fie containing the results of a duplicate bridge tournament and applies "stratification" to the results.

You can choose the ranks at which stratification occurs from the ranks of the Scottish Bridge Union and choose up to two strata from the overall results. The program is therefopre only useful for Scottish bridge clubs at the future. This might change in future.

More detailed information can be found in the Help installed with the program or read the markdown docs under helpsite.
