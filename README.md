# pairs-stratification
Pairs Stratification for Scottish bridge clubs, written in Python.

# What does it do?
The program consumes a USEBIO format XML fie containing the results of a duplicate bridge tournament and applies "stratification" to the results.

You can choose the ranks at which stratification occurs from the ranks of the Scottish Bridge Union and choose up to two strata from the overall results. The program is therefopre only useful for Scottish bridge clubs at the moment. This might change in future.

Once the ranks are chosen, you have the option to modify those to allow for visitors or players from other NBOs.

More detailed information can be found in the Help installed with the program or read the markdown docs under helpsite.

PLease report issues using the Issues page of this Github repository. You will find a stratlogs\stratlog.log file under your Windows user directory (e.g. C:\Users\myuser\stratlogs\stratlog.log). Please attach this to any issue you raise.
