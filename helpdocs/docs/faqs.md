# Frequently Asked Questions

## What happens if I open a USEBIO file that has already been stratified?
The already stratified results will be loaded. Displaying the **Stratify Tournament** page will show you the ranks used in stratifying that event
and a summary of the number of pairs in each stratum. You can change the stratification levels and click the Stratify button to re-stratify the event to new levels that you select.

## Does the utility work with single-winner or two-winner pairs events?
It will work with one and two winner events. **However, stratification usually works better with one-winner events.**

The reason for this is that if most of the higher-ranked pairs are playing in the same direction in a two-winner event, along
with a lower-ranked pair, stratification can be unfair. The lower-ranked pair are unlikely to get any masterpoints in the overall
rankings and, since there are insufficient pairs of their rank in the same direction in a lower stratum, no stratum masterpoints would be awarded.

Conversely, the other direction may be mostly pairs of a similar rank to them and there will be enough pairs in the stratum to
get stratified masterpoints.

With a single winner tournament, both directions are combined and stratification becomes much fairer.

So, with stratification, it's better to have a one-winner event (e.g. arrow-switching the last round or playing a Howell).

## What levels should I set the strata rankings to?
That's really up to you. The best thing is to try it out on some existing events, varying the strata levels and decide for yourself.

A common approach is to have just stratum B and set the stratification level to "5 Star Senior Master" so that stratum B consists of just bronze pairs, or to set the stratification level to "District Master" so that Bronze 2 and lower are in stratum B.

The important thing is to get a fair balance in a mixed-ability event that rewards lesser-ranked pairs who performed well with respect to their peers.

## What happens to stratification if a gold player plays with a bronze player?
When stratifying a tournament, **the highest ranked player of a pair** is used to determine the stratum they will be allocated.

## Does the utility work with Teams events?
No. It only works with pairs events. If you try and load up the results from a Teams event, you will get an error message telling you this is not a pairs event.

You may also get this error displayed if there is a fault in the input USEBIO file.

## Does the utility work with increased masterpoints scales, e.g. for district events?
No. Although this is something we may add if there is suffficient interest. Presently it uses the CLUB scales of masterpoints only.

## Why are output files named the way they are?
We named output files this way so that it's easy to sort the directory of files by ascending/descending date. You can rename any output file to suit your own needs.
